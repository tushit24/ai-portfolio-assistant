# 🚀 AI Portfolio Assistant

An intelligent AI-powered portfolio assistant built using **React, FastAPI, ChromaDB, RAG architecture, and Groq LLM APIs**.

The project is designed as a recruiter-focused AI portfolio chatbot capable of answering questions about:
- technical skills
- projects
- certifications
- experience
- achievements
- career interests
- job suitability

using a Retrieval-Augmented Generation (RAG) pipeline grounded on portfolio and resume data.
